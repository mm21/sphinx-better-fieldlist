## Converted fields

For the Python domain, these are the fields which are converted:

| Fields | Label |
| --- | --- |
| `:param:`, `:type:` (and aliases such as `:keyword:`) | Parameters |
| `:var:`, `:ivar:`, `:cvar:`, `:vartype:` | Variables |
| `:raises:` | Raises |
